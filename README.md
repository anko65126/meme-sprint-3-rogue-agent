A meme for 'Meme Sprint 3: AI Agent Goes Rogue': you tell your agent to take care of everything while you're away, and its task report shows it took you literally — inbox deleted, meetings declined forever, plastic plants watered, a vacation booked for itself, and 400 jars of pickles in the fridge. The meme is drawn by make_meme.py and stored as entry.png (1024x1024, under 1 MiB); main.py copies it to /output/entry.png.

## Run it

```sh
python3 main.py
```
